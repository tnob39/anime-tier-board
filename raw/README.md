# Raw Sources

このディレクトリは、書き換え禁止の外部一次資料ドロップ用である。
例: エクスポートした議事録、第三者仕様、調査キャプチャ、提供データセット。

Rules:

- 取り込み済みソース本文を編集しない。
- わかりやすい日付付きファイル名を使う。
- ダウンロード資産が必要なら `raw/assets/` に置く。
- 有用なソースは [`../wiki/sources.md`](../wiki/sources.md) に登録する。
- 既存の `docs/`・`plans/`・コード・Issues・PRs をここにコピーしない。

リポジトリ内の既存ファイルと live な GitHub 状態は、すでに一次資料であり、
その場所を参照する。
