# Component Page Guide

ソースファイル単位ではなく、耐久するプロダクト / 技術領域ごとに 1 ページを作る。
**本ディレクトリの個別ページは将来要件**であり、現時点では未作成。

各コンポーネントページが答えるべきこと:

- どのユーザー / システム責務を持つか
- どのルート・コンポーネント・ライブラリ・API が実装するか
- 現行の挙動と不変条件は何か
- どの承認済み決定が変更を制約するか
- 繰り返し調査が必要なエッジケースは何か
- どの一次資料が主張を証明するか

関連実装や調査のあとは、新規作成より既存ページ更新を優先する。
独立ロードに広すぎたら分割する。
