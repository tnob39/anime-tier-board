# Decision Page Guide

将来の作業を制約する**承認済み決定**だけを ADR 風ページにする。
提案は受理されるまで `docs/` または `plans/` に残す。
**個別 ADR ページは将来要件**であり、現時点では未作成。

推奨ファイル名:

```text
NNNN-short-decision-name.md
```

推奨セクション:

1. Context
2. Decision
3. Consequences
4. Supersedes or superseded by
5. Sources

撤回された決定は削除せず `historical` にし、新しい決定へリンクする。
