## 重要：法的助言ではない

本規程は、投稿担当が権利侵害・ネタバレ・炎上・無断転載を防ぐための**社内／プロジェクト内の運用ルール**です。

**法律上の助言・弁護士見解・権利関係の最終判断を示すものではありません。**

個別案件で法的判断が必要な場合は、責任者経由で専門家に相談してください。プラットフォーム規約・国内法令・権利者の利用条件が本規程より厳しい場合は、**より厳しい方に従います**。

## 1. 目的と適用範囲

### 1.1 目的

投稿量を増やす前に、次のリスクを予防し、問題発生時の初動を統一する。

- 著作権・肖像・商標などの権利侵害
- ネタバレによるユーザー・権利者への迷惑
- 誹謗中傷・煽り・未確認情報による炎上
- UGC（ユーザー生成コンテンツ）の無断転載

### 1.2 適用外（本規程だけでは足りないもの）

- 有料広告クリエイティブの媒体審査（別途広告ポリシーを確認）
- 個人の私的アカウント投稿（公式アカウントを装う行為は禁止）
- 法的クレーム対応の最終合意文面（責任者＋必要に応じ専門家）

### 1.3 投稿開始前の必須ゲート（on-call台帳）

公式投稿を開始する前に、**非公開の on-call 台帳**へ次を登録すること。

- 当番（氏名または社内識別子）
- 連絡手段（台帳内のみ。本規程・公開ドキュメント・投稿本文へ実在個人の連絡先を書かない）
- 代理当番
- Product Owner（最終A）への到達経路（台帳内）

**未登録のまま公式投稿を行うことは禁止。** 台帳はリポジトリ外の非公開領域で管理し、本規程に実在個人の氏名・電話・メール等を推測・公開しない。

## 2. 素材利用の原則（画像・映像・音源・引用）

### 2.1 共通原則

| 原則 | 運用上の意味 |
|------|----------------|
| 許諾優先 | 「公式だから使える」とは限らない。公式サイト／プレスキット／配信公式の**利用条件を毎回確認**する |
| 最小限 | 引用・切り出しは目的達成に必要な範囲だけ |
| 主従関係 | 投稿の主は本サービスのコメント／Tier／案内。他者作品が主にならない |
| 出典明示 | 作品名・公式アカウント／公式ページURL／権利者名を明示する |
| 疑義は停止 | 判断に迷ったら投稿しない。責任者にエスカレーション |

### 2.2 引用の必要条件（すべて必須）

文章・台詞・歌詞・他者コメント等を引用する場合、次を**すべて**満たすこと。1つでも欠ける場合は引用しない。

| # | 必要条件 | 意味 |
|---|----------|------|
| 1 | 公表済み | 引用元が既に一般に公表されている（非公開・限定共有・リークは不可） |
| 2 | 引用の必然性 | 批評・紹介・案内の目的上、その箇所を示す必要が説明できる |
| 3 | 引用部の明瞭区別 | 引用符・ブロック引用・「引用:」表記等で、自文と引用が読み手が区別できる |
| 4 | 主従関係 | 自らの解説・Tier・案内が主。引用が投稿の主内容にならない |
| 5 | 必要最小限 | 目的達成に必要な最短範囲に限る |
| 6 | 出典 | 作品名、話数（必要な場合）、公式または一次情報へのリンク／権利者名を付ける |

### 2.3 使用可／不可の具体例

| 種別 | 使用してよい例（条件付き） | 使用してはいけない例 |
|------|----------------------------|----------------------|
| 画像 | 公式がSNS二次利用を明示したキービジュアル、公式プレスキット内で利用条件を満たす素材、自作の図表・Tierスクショ（UI上の権利表示を残す） | アニメ本編の無断スクショ、BD/配信画面の録画キャプチャ、ファンアートの無断転載、他者投稿画像の転載、透かし除去 |
| 映像 | 公式が共有・埋め込みを許可したトレイラー／PVの**公式リンク共有**、自作画面録画のうちUI説明のみで本編を映さないもの | 本編カットの切り抜き、違法アップロードへのリンク、公式PVの無断再アップロード（媒体が公式再投稿を禁じる場合） |
| 音源 | 各媒体の商用／公式アカウント向けに許可された音源ライブラリ、権利処理済みBGM | 購入したCD・配信音源の転載、OP/ED音源の切り抜き投稿、カラオケ音源の無断利用 |
| 文章引用 | **§2.2の6条件をすべて満たす**、公表済み公式あらすじの短い引用＋出典＋明瞭区別、批評・紹介に必要な最小限の台詞引用 | 未公表・リーク文の引用、必然性のない長文抜き、引用と自文の区別がない転載、あらすじのほぼ全文、ネタバレ核心の長文、他メディア記事の丸写し、出典なし |

### 2.4 公式素材でも必須の確認チェック

投稿前に次をすべて満たすこと（1つでも No なら停止）。

1. 素材の提供元（公式サイト／配給／製作委員会／配信サービス等）が特定できている
2. 利用条件（商用可否、加工可否、クレジット文言、期間、媒体）を読んだ
3. 本サービスの用途がその条件に入っている
4. クレジット文言を条件どおり入れられる
5. 条件が読めない／曖昧 → **使用しない**（責任者判断待ち）

### 2.5 引用時の実務ルール

- §2.2の6条件をチェックリスト化して確認してから投稿する
- **改変**: 意味が変わる切り取り・誤認を招く加工はしない
- **台詞・歌詞**: 原則避け、使う場合は§2.2を厳格適用し、さらに短くする

## 3. ネタバレ運用（最新話48時間ルール）

### 3.1 定義

| 用語 | 定義（本規程） |
|------|----------------|
| 最新話 | 国内主要配信／放送で当該エピソードが**初めて一般視聴可能になった時点**の話数 |
| 48時間窓 | 上記公開時刻から**48時間以内** |
| 結末／核心ネタバレ | 生死・正体・告白・勝敗・重大伏線回収など、未視聴者の体験を大きく損なう情報 |

### 3.2 公開時刻の基準

1. **基準時刻**: 当該エピソードが、日本向けに公式配信または公式放送で視聴可能になった**最初の時刻（JST）**
2. 複数プラットフォームで時刻が異なる場合は、**最も早い公式公開時刻**を採用する
3. 時刻が公式に確認できない場合は、**より遅い確実な時刻**を採用する（早めにネタバレしない）
4. 記録: 投稿下書きまたは投稿ログに「基準時刻・根拠URL／公式発表」を残す

### 3.3 48時間窓での必須対応

| 項目 | ルール |
|------|--------|
| 本文冒頭警告 | 最新話に触れる投稿は、本文**先頭**にネタバレ警告を置く（例: `【ネタバレ注意｜第○話／公開から48時間以内】`） |
| サムネ・封面 | 結末／核心を示す構図・文字・記号を置かない |
| 先頭文・キャプション先頭 | 結論・正体・衝撃事実を書かない（警告の後に概括から入る） |
| altテキスト／画像説明 | 結末／核心を書かない（アクセシビリティ用でも同様） |
| ハッシュタグ | ネタバレ内容そのものをタグにしない |

### 3.4 例外承認

48時間以内に核心に触れざるを得ない投稿（緊急訂正、重大な誤情報の打消し等）は、**事前に責任者の書面承認（チャット可）**を得る。
承認記録には「理由・対象話数・公開予定時刻・承認者・承認時刻」を残す。承認なしの例外投稿は禁止。

### 3.5 48時間経過後

警告は推奨（特にシリーズ全体の重大ネタ）。サムネ・先頭文への核心露出は引き続き避ける。

## 4. UGC（ファン投稿・ファンアート等）の利用

他者の投稿・イラスト・写真・動画・文章を公式が使う場合は、次をすべて満たす。

### 4.1 必須要件

| # | 要件 | 内容 |
|---|------|------|
| 1 | 明示同意 | DM／フォーム／メール等で、利用の可否について**明示的な同意**を取得（いいねや絵文字だけの推定同意は不可） |
| 2 | 権利保証 | 投稿者が「自分に投稿権限がある」ことを確認（第三者作品の又貸しは不可） |
| 3 | クレジット | 表示名（ハンドル）および可能ならプロフィールURLを投稿内に記載 |
| 4 | 用途・媒体・期間 | 使う媒体、加工の有無、掲載期間（例: 7日間／キャンペーン終了まで／無期限）を同意時に明示 |
| 5 | 撤回受付 | 撤回連絡先と、下記の撤回期限を同意時に明示する |

### 4.2 撤回期限（統一）

| 区分 | 起算 | 期限 | 対応 |
|------|------|------|------|
| 通常の撤回受付 | **受信時刻**（営業時間内外を問わず） | **24時間以内**に削除または非公開 | 受付記録→削除／非公開→台帳更新 |
| 権利・プライバシー・安全の重大申告 | **認知時刻** | **15分以内**に暫定非公開（または削除） | 暫定措置後に事実確認・本削除・エスカレーション |

重大申告の例: 著作権者本人／代理人からの削除要請、肖像・プライバシー侵害の申告、脅迫・安全懸念に関わるUGC再掲の指摘。

### 4.3 同意取得テンプレ（コピー用）

```text
【UGC利用のお願い｜Anime Tier Board】
投稿（URL: ）を、次の条件で公式SNSに掲載してよいでしょうか。
・媒体: （例: X / Instagram）
・用途: （例: 今週の注目Tier紹介）
・加工: （なし／トリミングのみ／等）
・期間: （例: 掲載から14日）
・クレジット: （表示名とURL）
ご同意いただける場合は「同意する」とご返信ください。

【撤回について】
・通常の撤回: ご連絡の受信時刻から24時間以内に削除または非公開します（営業時間外も受信時刻起算）。
・権利・プライバシー・安全に関する重大な申告: 認知後15分以内に暫定非公開（または削除）します。
撤回は本連絡の返信にて受け付けます。
※本連絡は運用上の確認であり、法的助言ではありません。
```

### 4.4 撤回・削除手順

1. 撤回連絡を受けたら**即時に受付記録**を残す（受信日時・相手・対象URL・区分: 通常／重大）
2. 区分に応じ §4.2 の期限内に削除または暫定非公開する
3. 同一素材の他媒体・下書き・素材フォルダも削除
4. 削除完了を責任者（MVPでは Product Owner）に報告し、同意記録に「撤回・削除済み」を追記
5. 再掲載は**新たな明示同意**がある場合のみ

### 4.5 禁止

- 同意前の掲載・ストーリーズ使用・スクリーンショット再アップロード
- 同意範囲外媒体への横展開
- クレジット削除・あたかも自作であるかのような見せ方

## 5. 誹謗中傷・煽り・未確認情報・敬意

### 5.1 投稿前チェック（必須）

| チェック | Yesの状態 | Noのとき |
|----------|-----------|----------|
| 特定個人・団体への侮辱・嘲笑がない | 作品・制度・体験の話に留めている | **停止** |
| 煽り（炎上誘発目的の比較・煽動）がない | 建設的な紹介・注意喚起になっている | **停止** |
| 未確認情報を断定していない | 一次情報または公式発表に根拠がある | **停止**または「未確認」と明記して責任者確認 |
| 推測・噂を事実のように書いていない | 推測は推測と明示、または削除 | **停止** |
| 作家・声優・制作会社・配信事業者への敬意 | 批判があっても人格攻撃・決めつけがない | **停止** |

### 5.2 敬意の実務指針

- 制作・声優・スタッフへの感謝や労いを優先し、失敗・炎上ネタの拡散を目的にしない
- 「中の人」個人のプライベート推定をしない
- 他サービスとの比較は事実関係が確認できる範囲に限り、貶める表現を避ける
- センシティブな社会問題と作品を結びつける場合は、責任者確認を必須とする

### 5.3 コメント欄

公式コメント返信も本規程の対象。暴言・個人攻撃には共感せず、必要なら非返信／非表示／通報＋記録。

## 6. 訂正・削除・重大炎上のSLA

数値は**目標対応時間（業務優先度）**。法的義務の宣言ではない。

### 6.0 適用時間帯・監視・当番

| 項目 | ルール |
|------|--------|
| 公式投稿の実施中 | 当番が通知（メンション／DM／媒体アラート）を監視する |
| 公開後24時間 | 当該投稿について当番が通知監視を継続する |
| L1 / L2 の起算 | 原則として当番が認知した時刻。公開後24時間内は当番監視下の通知受信を認知候補とする |
| L3 の起算 | **24時間365日、受信時刻（または確実な認知時刻）起算**。営業時間の内外を問わない |
| 当番不応答 | L3（および緊急の重大申告）で当番が**5分以内に応答しない**場合、代理当番へ。代理も不応答なら **Product Owner** へ |
| 連絡先の扱い | 実在個人の電話・メール・住所等を本規程・公開投稿・公開ドキュメントに推測・記載・公開しない。連絡は非公開 on-call 台帳の経路のみ |

### 6.1 深刻度定義

| レベル | 例 | 初動（起算から） | 後続の一次対応完了 | エスカレーション |
|--------|----|------------------|--------------------|------------------|
| L1 軽微 | 誤字、リンク切れ、軽微な事実誤認 | 4時間以内に認知・着手 | 24時間以内に訂正または削除 | 投稿担当 → SNS運用リード（日次共有で可） |
| L2 中度 | 権利指摘、ネタバレ苦情、中規模の批判拡散 | 1時間以内に認知・着手 | 6時間以内に訂正／謝罪／削除方針を公開または実施 | 即時に SNS運用リード。必要なら Product Owner |
| L3 重大 | 権利者からの正式指摘、大規模炎上、**個人情報の露出、脅迫・安全懸念** | **認知後ただちに暫定非公開（または削除）。目標15分以内（必須）** | **60分以内**は一次声明／状況説明／次方針の承認など**後続対応のみ**（非公開の完了期限ではない） | 即時に Product Owner（最終A）。必要なら専門家 |

**L3の語義（矛盾防止）**

- **暫定非公開／削除**は初動の必須措置であり、認知後ただちに行う（目標15分以内）。60分枠に延ばさない。
- **60分以内**に含めるのは、短い一次声明、現状の状況説明、次方針（本削除の維持／部分再掲の可否等）の Product Owner 承認、必要なら専門家相談の開始、に限る。
- 「60分以内に削除／非公開する」という読み方はしない。非公開は15分目標の初動側に属する。

### 6.2 一次対応の型（優先順位）

1. **止める（最優先・L3では必須初動）**: 問題投稿の暫定非公開／削除／連投停止。L3は認知後ただちに実施（目標15分以内）
2. **事実確認**: 何が誤っているか、根拠は何か（L3では非公開の後に行う）
3. **伝える（L3の60分枠に含めてよい後続）**: 短い一次声明・状況説明（確認中／お詫び／次の連絡予定）。推測で弁解しない
4. **次方針の承認（L3の60分枠）**: 本削除の維持、追加声明の要否、再開条件などを Product Owner が承認
5. **証跡の保全**: §6.3に従う（L3の個人情報／脅迫等は下記の例外ルール。非公開を遅らせない）
6. **上げる**: SLAどおりエスカレーション（L3は初動と同時に Product Owner へ）

### 6.3 証跡の保全（L3・個人情報／脅迫等の特例を含む）

**原則（L1/L2、および安全上の遅延がないL3）**

- 投稿URL、投稿本文、メディア、投稿時刻（JST）
- 問題認知の経路（メンション、DM、メール、社内報告）
- 対応タイムライン（認知・判断・実行の時刻と担当）
- 対外コメント文面の最終版と承認者

**L3で個人情報露出・脅迫・安全懸念がある場合（本文とチェックリストで同一）**

1. **即時非公開（または削除）を証跡保存より優先する**
2. 事前のスクリーンショット等の保存は、**安全を損なわず、非公開操作を遅延させない場合に限る**
3. 遅延する／危険がある場合は、先に非公開・削除し、**管理画面・監査ログ・媒体側ログから事後保全**する
4. 保全物に残る個人情報は最小限にし、公開チャネルへ再掲しない

### 6.4 重大炎上時の追加ルール

- 個人判断での長文釈明・論争・相手の名指し非難は禁止
- 公式の追加投稿は Product Owner またはその委任を受けた運用リードの承認後のみ
- 同一趣旨の再炎上防止のため、類似草稿を点検してから再開

## 7. 媒体公式規約・著作権／コミュニティガイドライン（確認日: 2026-08-23）

確認方法: 公式ドメインへのHTTP取得または公式ページ本文の取得。ボット制限で自動取得が403の場合でも、公式ヘルプ本文が取得できたものは掲載。確認できなかったURLは推測せず「要確認」。

### 7.1 X

| 種別 | URL | 確認日 | 結果 |
|------|-----|--------|------|
| 利用規約（Terms） | https://x.com/en/tos | 2026-08-23 | 確認済（HTTP 200） |
| コミュニティ／ルール（The X Rules） | https://help.x.com/en/rules-and-policies/x-rules | 2026-08-23 | 確認済（公式ページ本文取得。一部クライアントは403の場合あり） |

## 8. 役割（RACI）と責任者

R = Responsible（実行） / A = Accountable（最終責任） / C = Consulted（相談） / I = Informed（共有）

**MVPにおける最終A（Accountable）は Product Owner とする。** SNS運用リードがいる場合も、L3・規程改定・投稿開始ゲートの最終責任は Product Owner。

| 活動 | 投稿担当 | SNS運用リード（任意） | Product Owner（最終A） | 専門家（必要時） |
|------|----------|----------------------|------------------------|------------------|
| 投稿開始ゲート（on-call台帳登録） | R | C | **A** | — |
| 通常投稿の作成・予約 | R | C | **A** | — |
| 素材利用条件の確認 | R | C | **A** | C |
| ネタバレ例外承認 | C | R | **A** | — |
| UGC同意取得・記録 | R | C | **A** | — |
| L1 訂正 | R | C | **A** | — |
| L2 権利・苦情対応 | R | R | **A** | C |
| L3 重大炎上・法的示唆 | C | R | **A** | C |
| 本規程の改定 | C | R | **A** | C |

### 8.1 公開ドキュメントに書かないもの

- 実在個人の氏名・電話・メール・住所などの連絡先
- on-call 台帳の中身（非公開領域のみ）

責任者の到達先は **非公開 on-call 台帳**にのみ置き、§1.3 のゲートを満たすこと。
